## Before you publish
Open `lessons.html`, search for `YOUR-EMAIL@example.com`, and replace it with a parent's email address.

## Putting it on GitHub Pages
1. Create a new **Public** repository on github.com.
2. Click **uploading an existing file**. Drag in **every file** in this folder (all 6 `.html` files, `styles.css`, and `README.md`) plus the `images` folder. Then click **Commit changes**.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and click **Save**.
4. After 1–3 minutes, the site will be live at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

If a page looks unstyled, `styles.css` didn't upload. If photos are missing, the `images` folder didn't upload.
